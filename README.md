# Assignment Overview
Build and execute a bioinformatics pipeline using sequence alignment (muscle) and 
profile hidden Markov models (hmmer) to search for a gene family across multiple 
bacterial proteomes.

## Required Tools
muscle for multiple sequence alignments (MSA)
hmmer for gene searching

### Resources from Dr. Mishra
* https://bip.weizmann.ac.il/education/materials/gcg/hmmanalysis.html
* https://en.wikipedia.org/wiki/HMMER
* Nature Biotechnology paper that explains HMMs written by the creator of hmmer
